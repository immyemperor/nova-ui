# Internationalisation

Visible text inside components (labels, placeholders, aria-labels, messages) comes from one catalogue with English defaults. Override any of it.

```ts
import { setMessages, DEFAULT_MESSAGES } from '@omni/core';

setMessages({
  close: 'Fermer',
  noResults: 'Aucun résultat',
  showingRange: 'Affichage de {from} à {to} sur {total}',
});
```

Call `setMessages` once before your first render. Values can contain `{placeholders}`, which components fill in. Keys you don't set stay in English.

## Finding keys

`DEFAULT_MESSAGES` lists every key with its English text. The type `MessageKey` is the union of those keys, so your editor autocompletes them.

## Locale-aware formatting

Dates, numbers and times use the browser's `Intl` APIs. Pass `locale` to a component to override the browser default:

```html
<ui-date-picker locale="fr-FR" name="start"></ui-date-picker>
<ui-counter value="12840" locale="de-DE"></ui-counter>
```

## Right-to-left

Components and layout classes use logical properties, so `<html dir="rtl">` flips layout, padding, borders and alignment. Icons that imply a direction (arrows, chevrons) need flipping in your own CSS.
