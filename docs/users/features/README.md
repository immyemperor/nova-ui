# Feature guides

Each guide covers one area: what it's for, how to use it, the options that matter, and what to watch for. The [component reference](../../../packages/core/dist-docs/API.md) lists every prop, event, method and slot.

| Area | Guide | Components |
| --- | --- | --- |
| Text and choice inputs | [Forms](forms.md) | `ui-input`, `ui-textarea`, `ui-checkbox`, `ui-switch`, `ui-radio-group`, `ui-slider`, `ui-rating`, `ui-otp-input`, `ui-tag-input`, `ui-field` |
| Dates and times | [Dates and times](dates.md) | `ui-date-picker`, `ui-date-range-picker`, `ui-calendar`, `ui-time-picker` |
| Colour | [Colour](colour.md) | `ui-color-picker` |
| Floating UI | [Overlays](overlays.md) | `ui-modal`, `ui-drawer`, `ui-popover`, `ui-tooltip`, `ui-dropdown`, `ui-context-menu`, `ui-select`, `ui-command-palette`, `ui-toaster` |
| Navigation | [Navigation](navigation.md) | `ui-tabs`, `ui-accordion`, `ui-breadcrumb`, `ui-pagination`, `ui-stepper`, `ui-nav-menu`, `ui-menubar`, `ui-sidebar`, `ui-split`, `ui-collapse` |
| Data | [Data tables](data-tables.md), [Lists, boards and scheduling](lists-boards-scheduling.md) | `ui-table`, `ui-tree`, `ui-virtual-list`, `ui-sortable`, `ui-kanban`, `ui-scheduler` |
| Charts | [Charts](charts.md) | `ui-chart`, `ui-sparkline` |
| Files | [File upload](file-upload.md) | `ui-file-upload` |
| Rich text | [Rich text editor](editor.md) | `ui-editor` (separate package) |
| Content | [Safe HTML](safe-html.md), [Page blocks](page-blocks.md) | `ui-html`, page blocks |
| Feedback | [Feedback](feedback.md) | `ui-alert`, `ui-badge`, `ui-avatar`, `ui-skeleton`, `ui-spinner`, `ui-progress`, `ui-counter`, `ui-card`, dialogs |
| Motion | [Motion](motion.md) | `ui-reveal`, `ui-stagger`, `ui-marquee`, `ui-scroll-progress`, helpers |
| Look and feel | [Theming](theming.md), [Icons](icons.md), [Layout and CSS](layout-and-css.md) | `ui-theme-toggle`, `ui-icon` |
| Language | [Internationalisation](i18n.md) | `setMessages()` |
| Accessibility | [Accessibility](accessibility.md) | all |
| Helpers | [Utilities](utilities.md) | `confirm`, `prompt`, `toast`, CSV, validation, maths |
