@omni/css

Layouts that fit every screen

Mobile-first, cascade-layered CSS with layout primitives, a 12-column grid, container queries, a responsive utility set and CSS-only components. This page is built with it: resize the window, or drag the corner of any dashed box.

Breakpoints

App shell

This page is a nova-shell. On phones the regions stack in reading order. From md the sidebar becomes a column; from xl an aside can join it. Resize to watch it happen.

<div class="nova-shell nova-shell-sidebar nova-shell-aside nova-shell-sticky-side">
  <header class="nova-shell__header">…</header>
  <nav    class="nova-shell__sidebar">…</nav>
  <main   class="nova-shell__main">…</main>
  <aside  class="nova-shell__aside">…</aside>
  <footer class="nova-shell__footer">…</footer>
</div>

Only add nova-shell-sidebar / nova-shell-aside for the regions you use. Set --nova-shell-sidebar and --nova-shell-aside to change their widths.

nova-prose for long-form content

Wrap CMS or markdown output in nova-prose. It caps the line length at 65 characters and adds a calm vertical rhythm, so you never style each element.

  • Lists keep their indent
  • Links use the accent colour
Quotes get an accent rule on the start edge, which flips in right-to-left languages.

Before you ship

  • Works at 320px wide and at 400% zoom with no sideways scrolling (except tables and code).
  • Tested at 320, 390, 768, 1024, 1280 and 1536px, and phones in landscape.
  • Viewport tag allows zoom. No user-scalable=no.
  • Touch targets are at least 44px on touch screens, with room between them.
  • Keyboard: every control reachable, focus always visible, DOM order matches reading order.
  • Light and dark themes checked; any brand colour re-verified for contrast.
  • Reduced motion respected; nothing depends on animation.
  • Prints sensibly (nova-print-hidden on chrome you don't want on paper).
