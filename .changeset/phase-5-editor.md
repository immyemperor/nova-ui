Phase 5: new optional `@kvui/editor` package with `<ui-editor>`: configurable toolbar (presets or custom items),
slash commands, mentions, tables, links, text and highlight colour, task lists, drag/drop/paste image uploads and
file attachments through an `uploadHandler`. React and Angular get it through `@kvui/react/editor` and
`@kvui/angular/editor`. `ui-button` gains a `pressed` state, and core exports its positioning helpers.
