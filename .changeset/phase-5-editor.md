Phase 5: new optional `@nova-ui/editor` package with `<ui-editor>`: configurable toolbar (presets or custom items),
slash commands, mentions, tables, links, text and highlight colour, task lists, drag/drop/paste image uploads and
file attachments through an `uploadHandler`. React and Angular get it through `@nova-ui/react/editor` and
`@nova-ui/angular/editor`. `ui-button` gains a `pressed` state, and core exports its positioning helpers.
